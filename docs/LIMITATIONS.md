# 完成範囲と制約

- 公開の固定Bearerキーと架空CSVを使うローカルデモ。本番認証、利用者登録、OIDC、秘密鍵ローテーションは未実装。
- CSV商品マスターの追加のみ。上書き・削除・在庫増減・決済・外部サービス接続はしない。
- SKUは組織内で一意。不正CSV・既存SKU重複は全件拒否する。修正版は新しい要求キーで作成する。
- リースは30秒で更新なし。3回を超える処理やクラッシュはfailedになる。厳密なコミット時刻を基準とした期限保証はない。
- PostgreSQLのジョブ表を使い、Kafka/RabbitMQ等は使わない。外部配送のexactly-onceを保証しない。
- 組織内20件の待機上限は永続データ総量の制限ではない。入力CSV・監査の保管期限・消去・改ざん検知は未実装。
- UIは最新50ジョブ・先頭50商品、履歴は最新50件。APIのページ指定は可能。集計と一覧は別取引で、同じ瞬間のスナップショットではない。
- CSVの行番号はヘッダーを1行目とした論理レコード番号。引用フィールド内の改行があった場合の物理行位置ではない。
- 作成再送の記録は画面メモリ内。再読込・別利用者への切替後は保持しない。無応答時は既存ジョブを確認する。
- 金額は整数円のみ。通貨換算・税計算・会計処理は実装しない。
- 構造化ログはあるが、アラート・メトリクス収集基盤・バックアップ復旧・長期稼働・大規模負荷は未検証。
- DBユーザーは初期DDL権限を持つ。本番では移行・実行ロールの分離が必要。
- 依存監査はCargo.lock上の未使用RSAに注意情報1件。選択ビルド経路に入った場合は検査を失敗させる例外ガードを同梱。無条件の無視や「指摘すべて0件」とはしていない。
- AWS配備、Terraform実行、Claudeによる反証レビューは今回未実施。
- Rustの実務年数・受託納品・本番導入の実績を示す作品ではない。Codexの検証は独立した人間の監査・第三者認証ではない。
- ライセンスは作品固有の条件を未指定。依存ライブラリには各ライセンスが適用される。

- GitHub上のCI結果は公開リポジトリのActionsを参照。過去の検証記録は各時点の実施範囲を示す。
